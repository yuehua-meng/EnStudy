## 执行（execute）

| 单词 | 美式音标 | 词性 | 含义 |

**execute**

The worker executes each task in a separate process.

工作进程在独立进程中执行每项任务。

搭配：execute a command；execute a task

用法提示：通常指执行程序、命令或任务；这里不收录非技术义项。

**execution**

Execution stops when an unhandled exception occurs.

搭配：execution time；execution context

关系：execute → execution（同族对应）

**executable**

The build produces a standalone executable.

构建会生成一个独立的可执行文件。

搭配：executable file；executable code

关系：execute → executable（同族对应）

**executor**

Submit the task to the executor.

将任务提交给执行器。

搭配：task executor；thread pool executor

关系：execute → executor（同族对应）
