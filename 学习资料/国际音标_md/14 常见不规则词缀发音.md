# 第14章 常见不规则词缀发音

| 单词 | 音标 | 释义 |
|---|---|---|
| dangerous | ['deɪndʒərəs] | 危险的 |
| famous | [ˈfeɪməs] | 著名的 |
| anxious | ['æŋkʃəs] | 焦虑的 |
| delicious | [dɪ'lɪʃəs] | 美味的 |
| generous | ['dʒenərəs] | 慷慨的 |

| discussion | [dɪˈskʌʃn] | 讨论 |
