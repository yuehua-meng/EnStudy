# 第17章 用音标背单词

## 用音标背单词的工具是什么？

用音标背单词的工具是发音规则，即 48 个音素是由哪些字母或字母组合发的。

发音规则是一种经验总结，适用于大多数的单词背诵，但也存在很多不符合规则的单词。

## 如何用音标背单词

1. 找出每一个音素对应的字母或字母组合。
2. 判断音素及其发音字母是否符合发音规则。
3. 符合规则的直接根据发音就能记住，不符合规则的单独记忆。

### 例词

| 单词 | 音标 | 释义 |
|---|---|---|
| dog | [dɒɡ] | 狗 |
| stone | [stəʊn] | 石子 |
| gather | ['gæðə] | 聚集 |
| appear | [ə'pɪə] | 出现 |
| traffic | ['træfɪk] | 交通 |
| distance | ['dɪstəns] | 距离 |
| important | [ɪm'pɔːtənt] | 重要的 |
| sympathetic | [sɪmpə'θetɪk] | 表示同情的 |
| aunt | [ɑːnt] | 姑；姨；婶；舅母 |

## 一个提醒

这一讲中列举的词缀并不是英语中全部的词缀，大家需要在背单词的过程中慢慢总结体会。
