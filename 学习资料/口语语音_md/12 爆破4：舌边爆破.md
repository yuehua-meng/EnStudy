# 第12章 爆破4：舌边爆破

## 什么是舌边爆破？

当"爆破音 + 舌侧音 [l]"时，爆破音的发音受到阻碍后进行不完全爆破。

## 舌边爆破

| 单词/例句 | 音标 | 释义 |
|---|---|---|
| mostly | [ˈməʊstli] | 主要地 |
| loudly | [ˈlaʊdli] | 大声地 |
| friendly | [ˈfrendli] | 友好的 |
| good luck | [ɡʊd-lʌk] | 好运 |
| would like | [wʊd-laɪk] | 想 |
| a big lake | [ə-bɪɡ-leɪk] | 一个大湖 |
| middle | [ˈmɪdl] | 中间 |
| candle | [ˈkændl] | 蜡烛 |
| a red lantern and a black lantern | [ə-red-ˈlæntən-ænd-ə-blæk-ˈlæntən] | 一个红灯笼和一个黑灯笼 |
| The third lesson was not long. | [ðə-θɜːd-ˈlesn-wəz-nɒt-lɒŋ] | 第三节课不长。 |
| Just let me sleep at lunch time. | [dʒʌst-let-miː-sliːp-æt-lʌntʃ-taɪm] | 就让我午餐时间睡觉吧。 |

## 爆破的总结

请记住：

1. 当爆破音遇到 [h] 时，[h] 音省略。
2. 当爆破音遇到 [j] 时，可以拼读。
3. 当爆破音遇到其他辅音时，爆破音不发音。
