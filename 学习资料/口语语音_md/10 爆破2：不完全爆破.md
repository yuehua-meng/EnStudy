# 第10章 爆破2：不完全爆破

## 什么是不完全爆破？

爆破音：

[p], [b], [t], [d], [k], [g]

摩擦音：

[f], [v], [s], [z], [θ], [ð], [ʃ], [ʒ], [h], [r]

破擦音：

[tʃ], [dʒ], [tr], [dr], [ts], [dz]

当"爆破音 + 摩擦音(除 h) / 破擦音"时，发音会受到一定程度阻碍。此时，爆破音只能轻微爆破。即发音器官做好发音的姿势，但基本不发音，稍作停顿后发后面的音。

## 爆破音+摩擦音

| 例句 | 音标 | 释义 |
|---|---|---|
| I'm not fat. | [aɪm-nɒt-fæt] | 我不胖。 |
| an old friend | [æn-əʊld-'frend] | 一个老朋友 |
| make sure | [meɪk-ʃʊə] | 确信 |
| a good view | [ə-ɡʊd-vjuː] | 好景色 |
| Read the latest version. | [riːd-ðə-ˈleɪtɪst-ˈvɜːʃn] | 读最新的版本。 |
