# 第4章 同化

## 什么是同化？

同化是指，两个相邻的音，为了发音更省力，使读音变的相近的现象。

## 同化现象

[t] + [j] 时，[t] 变成 [tʃ]

meet you
[miːt] + [juː] = [ˈmiːtʃ-juː]

[d] + [j] 时，[d] 变成 [dʒ]

would you
[wʊd] + [juː] = [wʊdʒ-ˈjuː]

[s] + [j] 时，[s] 变成 [ʃ]

this year
[ðɪs] + [jɪə] = [ˈðɪʃ-jɪə]

[z] + [j] 时，[z] 变成 [ʒ]

Tom is your friend.
[ɪz] + [jɔː] = [ɪʒ-ˈjɔː]

[s] + [ʃ] 时，[s] 变成 [ʃ]

this ship
[ðɪs] + [ʃɪp] = [ˈðɪʃ-ʃɪp]

[z] + [ʃ] 时，[z] 变成 [ʒ]

is she
[ɪz] + [ʃiː] = [ˈɪʒ-ʃiː]

## 总结

- [t] + [j] 时，[t] 变成 [tʃ]
- [d] + [j] 时，[d] 变成 [dʒ]
- [s] + [j]/[ʃ] 时，[s] 变成 [ʃ]
- [z] + [j]/[ʃ] 时，[z] 变成 [ʒ]
