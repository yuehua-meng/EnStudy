# 第2章 所谓清化

## 浊辅音存在清化现象吗？

浊辅音不存在清化现象。

浊辅音清化，通常定义为：

当构成"浊辅音 + 清辅音"形式的辅音连缀时，该浊辅音要念成对应的清辅音。

has + to = has to

[hæz] + [tuː] = [ˈhæs-tuː]

## 所谓"清化"，其本质是：

当构成"浊辅音 + 清辅音"形式的辅音连缀时，浊辅音不振动。

清辅音 [s]：有气流，声带无振动。

浊辅音 [z]：无气流，声带有振动。

例：has to 不得不，浊辅音 [z] 发音时声带不振动。
